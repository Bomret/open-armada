# Security policy

## Report a vulnerability

Report a vulnerability privately through GitHub:
<https://github.com/Bomret/open-armada/security/advisories/new>. Do not open a public issue for it.

Give the affected version or commit, the steps that reproduce the problem, and its effect. The engine
reads the files of a game install and layout files, so a crafted or corrupt file that makes the engine
misbehave beyond a reported read failure is in scope.

## Supported versions

Open Armada has no releases yet. Fixes go into `main`.
